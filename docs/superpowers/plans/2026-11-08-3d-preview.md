# テクスチャ付き 3D プレビューと renderView 実装計画

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** client.jar のモデルとテクスチャで描く 3D ビューアを作り、同じビューアをヘッドレスの Edge で撮影して AI に返す `renderView` ツールを追加する。

**Architecture:** Node 側は、アセットの取得（`src/preview/assets/`）、ブロック状態からクアッドへの焼き込み（`src/preview/models/`）、差分を配信する HTTP API（`src/preview/server.ts`）を担う。ブラウザ側（`src/preview/client/`、tsc で ES モジュールに出力）は、Worker でのメッシュ生成と three.js での描画を担う。メッシュ生成とカメラの計算は DOM に依存しない純粋なモジュールにして、Node の vitest でテストする。`renderView` は `playwright-core` でインストール済みの Edge を操作する。

**Tech Stack:** TypeScript, three（r171 以降）, fflate, playwright-core, vitest

**Spec:** `docs/superpowers/specs/2026-11-08-3d-preview-design.md`

**Execution:**
- Task 1、2：Sonnet のサブエージェント 1 体が通しで担当する。
- Task 3、4：難所なので、メインセッション（Opus）が担当する。
- Task 5〜8：Sonnet のサブエージェント 1 体が通しで担当する。
- 完了後、メインセッションが全体をレビューする。

## Global Constraints

- 座標は Minecraft と同じ（+X 東、−Z 北、+Y 上）。カメラの上方向は +Y。`north` は −Z 側から +Z を向く（画面の左が +X）。`top` は画面の上が −Z、右が +X。
- jar から取り出したテクスチャやモデルを、リポジトリやテストのフィクスチャに入れない。テストは自作のフィクスチャだけを使う。
- アセットのバージョン：`MC_SCHEMA_ASSET_VERSION`（既定 `1.21.11`）。キャッシュ：`MC_SCHEMA_CACHE_DIR`（既定 `./cache`）の `assets/<version>/`。
- 陰影：上 1.0、下 0.5、北と南 0.8、東と西 0.6。着色：草 `#91BD59`、葉 `#77AB2F`、水 `#3F76E4`。
- 解決できない ID は、マゼンタ（`#F800F8`）と黒の市松模様で描く。テクスチャの取得に失敗したときは、`colorFor`（`block-colors.ts`）の色で塗る。
- Worker から読み込むコードは `three` を import せず、相対パスの import だけを使う。
- ヘッドレスのブラウザは `--use-gl=angle --use-angle=swiftshader --enable-unsafe-swiftshader` を付けて起動する。
- 新しく追加する依存ライブラリは `three`、`@types/three`（dev）、`fflate`、`playwright-core` の 4 つだけ。
- 既存の 2D ビューアは `/2d` に移し、中身は変えない。

## Review Focus

- `north` / `south` / `top` のスクリーンショットが鏡写しにならないこと → Task 4 のカメラのテスト。
- 隣のチャンクが変わったときに、接続（フェンス、ガラス板）の見た目が更新されること → Task 5 のテスト（チャンクが変わると、隣の 6 チャンクも送り直す）。
- テクスチャが取得できない状態でも、ビューアが開けて `__previewReady` になること → Task 6 のテスト（アセットの状態が `failed` のときの経路）。
- 空になって削除されたチャンクが、ビューアから消えること → Task 5 のテスト（`since` 以降の削除が、状態 1 で送られる）。
- Edge が見つからないときと WebGL が作れないときに、理由の分かるエラーになること → Task 7 のテスト。
